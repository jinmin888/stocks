# Stock Screener 需求规格

> 状态：讨论中。每个条件均为可开关的独立模块，参数可配置。

## 1. RSI 背离（已确定）

### 参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `rsi_period` | 14 | RSI 周期 |
| `regular` | 开启 | 常规背离（顶/底） |
| `hidden` | 关闭 | 隐藏背离（顶/底），可选 |
| `min_gap` | 5 | 两个分型点之间最少 K 线数 |
| `max_gap` | 60 | 两个分型点之间最多 K 线数 |
| `oversold` | 30 | 常规底背离：第一个低点 RSI 须 < 此值（可关闭） |
| `overbought` | 70 | 常规顶背离：第一个高点 RSI 须 > 此值（可关闭） |
| `recent_bars` | 3 | 第二个分型须在最近 N 根 K 线内确认 |

### 规则

- **高低点来源**：顶底分型（与分型模块共用同一套识别结果）。
- **比较对象**：最新分型只与**前一个同类型**分型比较。
- **取值**：
  - 价格：底分型取中间 K 线最低价，顶分型取中间 K 线最高价（包含处理后的合并 K 线极值）。
  - RSI：取分型三根 K 线中 RSI 的极值（底取最小，顶取最大）。
- **背离定义**（P1/P2 为前/后分型价格，R1/R2 为对应 RSI）：
  - 常规底背离：P2 < P1 且 R2 > R1
  - 常规顶背离：P2 > P1 且 R2 < R1
  - 隐藏底背离：P2 > P1 且 R2 < R1
  - 隐藏顶背离：P2 < P1 且 R2 > R1
- **超买超卖过滤**：只作用于常规背离的第一个点；隐藏背离默认不应用。
- **强度分**：输出价格变化幅度、RSI 差值及综合强度分，仅用于排序，不作为过滤条件。

## 2. 顶底分型（部分确定）

### 包含关系处理（默认开启，可关闭）

- 相邻两根 K 线若一根的高低点完全包含另一根，则合并。
- 上升趋势取「高高」（高点、低点都取较大值），下降趋势取「低低」（都取较小值）。
- 趋势方向由前一根 K 线与再前一根 K 线比较决定。
- 合并 K 线：高低点用合并后的值，**收盘价取合并组中最后一根原始 K 线的收盘价**。

### 结构定义

- 顶分型：K2 高点最高、低点也最高。
- 底分型：K2 低点最低、高点也最低。

### 强度分级（三档，以底分型为例，顶分型对称）

| 强度 | 条件 |
|---|---|
| 强 | K3 为阳线，且 K3 收盘价 > K1 最高价 |
| 中 | K3 收盘价 > K1 实体中点 |
| 弱 | 仅满足分型结构 |

- K3 收盘价 > K1 最高价但 K3 为阴线：评为**中**。
- 可选成交量条件（`volume_check`，默认关闭）：开启后，评「强」还须满足 K3 成交量 > K2 成交量 且 > N 日均量（`volume_ma`，默认 5）；不满足则降一档（强→中）。

### 分型过滤（严格「笔」规则）

- 在包含处理后的 K 线上识别分型。
- 相邻的顶分型与底分型**不能共用 K 线**，且中间至少隔 1 根独立 K 线（即两个分型的 K2 之间至少相隔 4 根）。
- 顶底必须交替出现；连续出现同类分型时，只保留更极端的一个（顶取更高、底取更低）。
- 不满足间隔要求的新分型被忽略（若与前一个同类且更极端，则替换前一个）。

### 作为筛选条件

| 参数 | 默认值 | 说明 |
|---|---|---|
| `recent_bars` | 1 | K3 须为最近 N 根已收盘 K 线之一（默认即最新一根） |
| `min_strength` | 无 | 默认不按强度过滤，全部输出并标注 强/中/弱；可设为 中 或 强 |
| `confirm_k4` | 关闭 | 开启后要求 K4 不破 K2 极值（底分型不破 K2 最低价，顶分型不破 K2 最高价）；此时时效改为以 K4 计算 |

### 与背离模块联动

- 背离模块可设置第二个分型的最低强度（`divergence.min_fractal_strength`），默认不限制。
## 3. 市场与数据源（初定）

数据层做成统一接口，每个市场一个适配器，输出统一的 OHLCV 数据。

| 市场 | 数据源（默认） | 代码示例 | 备注 |
|---|---|---|---|
| 加密货币 | `ccxt`（默认 Binance，可换 OKX / Bybit 等） | `BTC/USDT` | 公开行情无需 API key |
| 韩国股市 | `pykrx`（KRX 官方数据） | `005930` | 覆盖 KOSPI / KOSDAQ |
| A 股 | `akshare` | `600519` | 免费，无需 key |
| 美股 | `yfinance` | `AAPL` | |
| 港股 | `yfinance` | `0700.HK` | |

### K 线周期

- 加密货币：`15m`、`1h`、`4h`、`1d`、`1w`、`1M`（直接从交易所获取）。
- 加密货币日线按 UTC 0 点切分。
- 股票：`1d`、`1w`、`1M`（周线、月线由日线合成）。
- 所有周期只使用**已收盘** K 线，正在形成中的最后一根 K 线丢弃。

## 4. 扫描范围与过滤

- 范围：自定义列表 / 指数成分股 / 全市场，行情数据缓存到本地，增量更新。
- 美股、港股默认扫指数成分股（如 S&P 500、恒生综合指数），全市场为可选项。
- 股票默认过滤（均可开关、可调）：
  - 剔除 ST 股（A 股）
  - 剔除 ETF / 基金
  - 剔除上市不满 60 天
  - 市值低于设定金额的剔除（每个市场单独设置，按当地货币）：
    A 股 50 亿 CNY、港股 50 亿 HKD、美股 10 亿 USD、韩国股市 1000 亿 KRW
  - 成交额门槛（可选）
- 加密货币：USDT 计价，按 24h 成交额取前 N（默认 100），剔除稳定币。

## 5. 组合逻辑

- 多个条件开启时默认 **AND**（全部满足），可改为 **OR**（任一满足）。
- 方向须一致：底背离 + 底分型 → 看涨；顶背离 + 顶分型 → 看跌。
- `direction`：`bottom`（只看底部）/ `top`（只看顶部）/ `both`（默认）。

## 6. 网站与部署（初定）

- 架构：FastAPI 后端 + React 前端；筛选核心为独立 Python 包，与 Web 层解耦。
- 界面语言：中文、韩文（可切换）。
- 定时扫描：按市场/周期定时自动运行；扫描任务与条件可在网页上新建、修改、启停。
- 部署：服务器部署（Docker Compose）。
- 登录：单用户，账号密码通过服务器环境变量配置，不做多用户系统。
- 结果：表格展示、CSV 下载；点击标的显示交互式 K 线 + RSI，标注分型强度与背离连线。
